## Two latent bugs the new tests exposed

1. `test_scheduler_restart_doublefire.py` assigned `core.database.engine` and
   `SessionLocal` directly instead of through `monkeypatch`, leaking an
   in-memory DB that only knew the two task tables. Latent until the
   admin-demotion fix started querying `ApiToken`; then `test_set_admin` failed
   with "no such table: api_tokens" in a full run but passed in isolation.
   Fixed (bf89cb2f).
2. `test_review_regressions.py` asserted that `enable_tool` re-enables the
   email set, and aborted after mutating shared settings once it no longer did.
   Updated to assert the refusal (e58daddc), which also removed the
   order-dependence.
